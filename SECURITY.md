# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

1. Go to [Report a vulnerability](../../security/advisories/new) in this repository's Security tab.
2. Describe the problem, how to reproduce it, and what someone could do with it. A suggested fix is welcome but not
   needed.

The report stays private until the problem is fixed.

## Scope

This repository holds the source of a static website, [samuelsenhet.github.io](https://samuelsenhet.github.io). In
scope are the site's code, its build and dependencies, the GitHub Actions workflow, and anything in the repository that
should not be public. The site has no backend.

## What happens next

The site is maintained by one person. Every report is read, and confirmed problems are fixed as soon as possible.
